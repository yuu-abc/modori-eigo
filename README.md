# もどり英語

休んでも、また戻れる英単語学習アプリです。

## GitHub Pages で公開する方法

1. GitHub のリポジトリで **Settings** を開く
2. 左の **Pages** を開く
3. **Build and deployment** の Source を **Deploy from a branch** にする
4. Branch を `main`、フォルダを `/(root)` にして **Save** を押す

数分後に表示される URL を開くと、`index.html` のアプリが表示されます。

## 内容

- 気分に応じて 1 語・5 語・10 語を選択
- 英検2級向け頻出単語を12語収録
- 「意味を見る」「次の単語」だけのシンプルな操作
